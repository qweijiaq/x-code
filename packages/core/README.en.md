# @x-code-cli/core

[简体中文](./README.md) · [English](./README.en.md)

Core AI engine powering [X-Code](https://github.com/qweijiaq/x-code).

This package is the headless runtime shared by the desktop app and `@x-code-cli/cli` — agent loop, tools, provider registry, and permission system. It has **no UI dependencies** and can in principle be embedded in other tools.

> ⚠️ The public API is not yet stable — breaking changes may happen between minor versions. If you just want to use X-Code, download the desktop app from the [main repository](https://github.com/qweijiaq/x-code) or build the CLI from source as described in its README.

For full installation, ChatGPT sign-in, API key setup, and usage, see the [main repo README](https://github.com/qweijiaq/x-code).
