# @x-code-cli/core

[简体中文](./README.md) · [English](./README.en.md)

[X-Code](https://github.com/qweijiaq/x-code) 的核心 AI 引擎。

本包是桌面端和 `@x-code-cli/cli` 共用的无头（headless）运行时，包含 Agent 循环、工具、模型厂商适配、权限系统等逻辑，**不依赖任何 UI 框架**，理论上可以嵌入到其他工具中使用。

> ⚠️ 公共 API 尚未稳定，小版本之间可能会有破坏性变更。如果你只是想使用 X-Code，请从[主仓库](https://github.com/qweijiaq/x-code)下载桌面端或按 README 从源码构建 CLI。

完整的安装说明、ChatGPT 登录与 API Key 配置、使用方式请看 [主仓库 README](https://github.com/qweijiaq/x-code)。
