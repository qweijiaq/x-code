# X-Code 1.0.4

Background task work, delivered in three steps: background shells free the
composer, background sub-agents can be delegated, and long turns can run in a
detached session.

## Background shells (A)

- A shell command that outlives its initial wait is reported as a background
  task with a model-facing note. The model is told not to poll just to wait.
- If the model makes one passive `shellOutput` wait and the command is still
  running, the reply ends instead of holding the composer. The background panel
  keeps tracking the process and the user can send the next prompt immediately.
- An idle banner shows the running task count with a **View** action.
- Explicit `block: false`, `yieldTimeMs: 0` and interactive input are left
  alone; those calls are status checks, not waits.

## Background sub-agents (B)

- `task` now accepts `background: true`. It returns a task id immediately; the
  sub-agent runs in its own `LoopState` while the main conversation stays
  usable.
- The background task panel lists sub-agent tasks alongside shell sessions,
  with status, elapsed time, tool-call count, result and a **Stop** action.
  Completion sends a system notification and a transcript notice.
- A background task can be stopped independently of the main reply; permission
  prompts still go through the normal approval UI.

## Detached continuation (C)

- A queued text prompt can be sent to a new window with **Continue in new
  window**. X-Code forks the last saved session, opens the copy in a new
  window and submits the queued prompt there, so the original window keeps
  running its current reply without sharing mutable state.
- The new window starts from the last committed transcript snapshot; partial
  output from the in-flight turn is not copied. Prompts with attachments stay
  in the queue for now.
- This is deliberately a separate window/runtime, not two writers in one
  transcript. Coding work should still avoid editing the same files in both
  windows; use a worktree when the tasks overlap.

## Install

1. Download `X-Code-1.0.4-arm64.dmg` and verify it:

   ```bash
   shasum -a 256 -c SHA256SUMS
   ```

2. Drag **X-Code** to Applications.
3. The community build is ad-hoc signed, not notarized. Approve the first
   launch in **System Settings → Privacy & Security → Open Anyway**; if macOS
   reports the app is damaged, clear the quarantine flag:

   ```bash
   xattr -dr com.apple.quarantine /Applications/X-Code.app
   ```

Full steps: [unsigned install guide](../desktop-install-unsigned.en.md).
