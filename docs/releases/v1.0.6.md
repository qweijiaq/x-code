# X-Code 1.0.6

An input-focused patch for IME handling and long drafts.

## IME and Enter

- Enter no longer sends while a Chinese IME is composing. The first candidate is
  committed normally, and a short window after `compositionend` is also
  protected from accidental submission.
- The same protection now covers the command palette, session rename, model
  search, custom model ID, in-session find, document questions, branch and
  worktree inputs, file creation, and settings search fields.
- `Esc` during composition only cancels the candidate instead of closing the
  palette, manual, settings or Inspector; arrow keys in the command palette no
  longer move the selected row while paging candidates.

## Composer

- The textarea grows with the draft up to about 240 px, then scrolls internally
  instead of staying one line high.
- Height is recalculated when the window resizes or the Inspector opens and
  narrows the column.

## Install

1. Download `X-Code-1.0.6-arm64.dmg` and verify it:

   ```bash
   shasum -a 256 -c SHA256SUMS
   ```

2. Drag **X-Code** to Applications.
3. The community build is ad-hoc signed, not notarized. Approve the first
   launch in **System Settings → Privacy & Security → Open Anyway**; if macOS
   reports the app is damaged, clear the quarantine flag:

   ```bash
   xattr -dr com.apple.quarantine /Applications/X-Code.app
   ```

Full steps: [unsigned install guide](../desktop-install-unsigned.en.md).
