# X-Code 1.0.0 — first desktop release

X-Code is a local-first coding agent. The CLI and the new desktop app share the
same runtime, tools and `~/.x-code` data, so sessions, memory, skills, plugins,
MCP servers and hooks carry over unchanged.

This release ships the **macOS arm64** desktop build. Windows and Linux builds
are configured in CI but are not part of the 1.0.0 support statement yet.

**Download:** [X-Code 1.0.0 release assets](https://github.com/qweijiaq/x-code/releases/latest)
(`X-Code-1.0.0-arm64.dmg`, `SHA256SUMS`, `RELEASE.json`).

## Highlights

- **Desktop app** — multi-window session tabs, branch worktree windows, image
  paste, screen capture, local Whisper voice input, Markdown composer and a
  unified document/Git/check/terminal inspector.
- **Search you control** — configure Tavily, Brave, Exa, Perplexity or Firecrawl
  in Settings → Tools → Search service, choose a preferred provider and test the
  connection. `webSearch` stays unavailable until a key is configured;
  `webFetch` is unaffected.
- **Knowledge and documents** — document library with local indexing, PDF /
  Word / Excel / CSV reading, OCR, spreadsheets and exports.
- **Extensions** — SkillHub and SkillsMP marketplaces, plugins, MCP servers,
  user/project hooks and persisted permission rules.
- **Sessions** — full-text search, pin/archive, Markdown/JSON/PDF export,
  checkpoints, rewind and fork.
- **Safety** — sandboxed shell on macOS, three-level permissions, crash
  recovery, redacted diagnostics export and user backup/restore.

## Install (macOS arm64)

1. Download `X-Code-1.0.0-arm64.dmg` and verify it against `SHA256SUMS`:

   ```bash
   shasum -a 256 -c SHA256SUMS
   ```

2. Open the dmg and drag **X-Code** to Applications.
3. The community build is ad-hoc signed, not notarized. On first launch macOS
   will block it — open **System Settings → Privacy & Security → Open Anyway**.
   If macOS says the app is damaged, clear the quarantine flag:

   ```bash
   xattr -dr com.apple.quarantine /Applications/X-Code.app
   ```

   Full steps: [unsigned install guide](../desktop-install-unsigned.en.md).

## First run

1. Open **Settings → Models & keys** and add a model provider key (or use a
   local Ollama / LM Studio model).
2. Optionally open **Settings → Tools → Search service**, paste a search key
   (Tavily has a free tier) and click **Test connection**.
3. Open **? → User manual** for the complete tour.

## Known limitations

- **Unsigned and not notarized.** No Apple Developer ID; Gatekeeper requires the
  manual first-launch approval described above.
- **Manual updates.** The app can check a release feed and download a verified
  installer, but does not install updates automatically (that requires a signed
  build).
- **macOS arm64 only.** Intel Mac, Windows and Linux installers are not part of
  this release and have not been accepted on real devices.
- Voice input, screen capture and the browser sub-agent need microphone /
  screen-recording permissions and were verified manually, not by automation.
