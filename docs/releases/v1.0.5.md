# X-Code 1.0.5

A conversation-surface refresh: the transcript now reads like a document rather
than a stack of boxes, while keeping the paper-and-ink identity.

## Conversation

- The transcript uses one measured column (840 px) with generous spacing.
  Assistant replies are plain editorial prose with a small seal; user prompts
  are warm, right-aligned cards instead of full-width labels.
- Tool calls are compact activity cards with a tool chip, a status dot, a
  right-aligned target and a pill-style result toggle. Diffs and sub-agent logs
  reuse the same card language.
- Markdown typography is reworked: clearer heading hierarchy, comfortable list
  and blockquote rhythm, inline-code pills, rounded/striped tables, rounded
  images, and quieter links.
- Code blocks have a terminal-style header with window dots, language label,
  wrap toggle and copy action.
- Attachments use larger rounded thumbnails; message actions are quiet pills
  that appear on hover.
- The composer is a rounded input surface with a single accent ring on focus;
  the empty state and starter suggestions are calmer and centered.
- Both light and dark themes are covered.

## Install

1. Download `X-Code-1.0.5-arm64.dmg` and verify it:

   ```bash
   shasum -a 256 -c SHA256SUMS
   ```

2. Drag **X-Code** to Applications.
3. The community build is ad-hoc signed, not notarized. Approve the first
   launch in **System Settings → Privacy & Security → Open Anyway**; if macOS
   reports the app is damaged, clear the quarantine flag:

   ```bash
   xattr -dr com.apple.quarantine /Applications/X-Code.app
   ```

Full steps: [unsigned install guide](../desktop-install-unsigned.en.md).
