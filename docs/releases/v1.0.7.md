# X-Code 1.0.7

Cost visibility, external-content taint approvals, and background task persistence.

## Costs and budgets

- The desktop settings now include a per-prompt token/USD budget and a per-model
  price editor. Prices are stored in `~/.x-code/config.json` and used by `/usage`
  and `--max-cost`.
- Cost estimates use the model breakdown, so fallbacks and sub-agents with a
  different model no longer reuse the primary model's price. Unpriced models show
  a partial-cost marker.

## External content taint

- New opt-in policy: `--external-content-policy approve` (CLI) or Settings →
  Permissions (desktop). After a web page, document, or MCP output is read in the
  current turn, later write/shell/`task` operations ask for approval again instead
  of reusing session auto-allow.
- Sub-agents inherit the parent's taint and propagate their own reads back to the
  parent. Background sub-agent snapshots carry the flag until their output is read.
- The desktop approval dialog and the CLI permission box show why the action is
  being asked again.

## Background tasks

- Background sub-agent snapshots are persisted per workspace under
  `.x-code/background-tasks.json`; unfinished tasks are restored as `interrupted`.
- Snapshots from multiple windows are merged instead of overwriting each other,
  are written with mode `0600`, and switching projects is blocked while a local
  background task is running.

## Observability and quality

- `xc trace [--last N] [--json]` reads local turn traces; diagnostics bundles
  include the last 20 turns.
- Added a v8 coverage gate and a high-severity dependency audit gate (plus
  CodeQL) in CI.
- Moved to zod 4 and removed the last production high-severity advisory.

## Install

The community build is unsigned. See
[the unsigned install guide](../desktop-install-unsigned.en.md) if macOS blocks
the first launch.
