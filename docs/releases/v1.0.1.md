# X-Code 1.0.1

A focused fix release for the macOS desktop app. No data migration is needed;
sessions, settings and keys are unchanged.

**Download:** [X-Code 1.0.1 release assets](https://github.com/qweijiaq/x-code/releases/latest)
(`X-Code-1.0.1-arm64.dmg`, `SHA256SUMS`, `RELEASE.json`).

## Fixes

- **Chinese input no longer sends by accident.** Pressing Enter to confirm an
  IME candidate (Pinyin, Japanese, Korean, etc.) is ignored by the composer;
  only a real Enter submits.
- **The agent and built-in terminal now see tools you install later.** The app
  re-reads `PATH` and other exports from your login shell, opens new terminal
  tabs as login shells, and refreshes the environment before each turn (cached
  for 30 seconds). Keys stored in X-Code still win over shell exports.
- **Skills reload without restarting.** Settings → Skills now has **Rescan**
  and **Refresh environment** buttons. The app also watches skill directories
  and picks up externally installed skills within a few seconds.
- **Nested skill layouts are discovered.** `skills/@scope/<name>/SKILL.md`
  installs from third-party tools now appear alongside `skills/<name>`.
- **The app icon has a transparent background.** The white square around the
  icon is gone; the artwork follows the macOS icon grid.
- **Resumed sessions no longer compact at a few percent.** The compaction check
  now compares the live context size, not the cumulative input tokens of the
  whole session. A long resumed conversation no longer looks "full" on its
  first turn.
- **You can queue prompts while a turn is running.** Press Enter to add the
  message to the queue; it runs when the current turn ends. The Stop button
  ends the reply but leaves already-backgrounded shell tasks running.
- **Background tasks show progress.** The panel now displays elapsed time,
  output size, a running count and a progress bar: a real percentage when the
  command prints one, an indeterminate bar otherwise.
- **Less jitter while code streams.** Partial code blocks are no longer
  re-highlighted on every delta, and auto-scroll waits for the frame to settle.
- **New sessions show up immediately.** A new tab and sidebar row take the first
  prompt as their title right away, and the session list refreshes while a long
  turn is still running instead of waiting for it to finish.

## Conversation outline

The right-hand inspector has a new **Outline** tab (also in the Tools menu and
the top bar). It lists every question and answer in the current conversation;
click one to jump straight to it without scrolling. Auto-follow pauses after a
jump, and the “back to bottom” button resumes it.

## Install

1. Download `X-Code-1.0.1-arm64.dmg` and verify it:

   ```bash
   shasum -a 256 -c SHA256SUMS
   ```

2. Drag **X-Code** to Applications.
3. The community build is ad-hoc signed, not notarized. Approve the first
   launch in **System Settings → Privacy & Security → Open Anyway**; if macOS
   reports the app is damaged, clear the quarantine flag:

   ```bash
   xattr -dr com.apple.quarantine /Applications/X-Code.app
   ```

Full steps: [unsigned install guide](../desktop-install-unsigned.en.md).

Existing 1.0.0 users can open **Settings → Desktop updates**, check for 1.0.1,
download the dmg, and install it manually. Automatic installation still
requires a signed build.
