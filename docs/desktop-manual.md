# X-Code 桌面端用户手册

这是一份面向日常使用的完整说明：从第一次配置模型，到会话、文档、Git、技能市场、权限与备份。界面上的入口如果找不到，可以先按 `Cmd/Ctrl+K` 搜索能力名称。

## 快速开始

1. 启动 X-Code Desktop。首次启动会显示引导页，选择模型提供商并填写 API Key；也可以先跳过，在 **设置 → 模型与密钥** 中配置。
2. 在侧栏选择或添加项目文件夹。桌面端与 CLI 共用 `~/.x-code`，已有会话、技能、插件和记忆会自动出现。
3. 在输入框描述任务，按 `Enter` 发送；`Shift+Enter` 换行。
4. 需要查看项目文件、文档、Git 或终端时，使用输入框工具栏或右侧 Inspector。
5. 不确定有什么能力时，输入 `/` 查看全部命令，或按 `Cmd/Ctrl+K` 打开命令面板。

没有配置 API Key 时，应用会使用演示模型，只用于体验界面，不会真正调用模型。

## 界面总览

![主界面](shot:chat)

- **顶栏**：模型选择、任务模式、侧栏开关、终端、设置、更多工具。
- **侧栏**：项目、上手清单、会话列表。可以搜索、置顶、归档、重命名和导出会话。
- **会话标签**：一个窗口可以打开多个会话标签，`Cmd/Ctrl+T` 新建标签，`Cmd/Ctrl+Shift+N` 新建窗口。
- **右侧 Inspector**：文档、Git、项目检查、终端、文件浏览器和对话目录共用一个可调整宽度的侧栏。
- **输入区**：Markdown 工具栏、附件、截图、语音、发送/停止按钮；下方显示上下文用量和“全部能力”入口。

## 会话与标签页

- **新建会话**：侧栏 `＋`、`Cmd/Ctrl+N` 或 `Cmd/Ctrl+T`。第一次提问后，标签和侧栏会立即用问题作为标题；消息在对话过程中持续写入磁盘，长任务未结束时侧栏也会刷新，不需要等整轮结束。
- **切换会话**：点击侧栏条目或顶部标签；切换时当前输入草稿会保留。
- **搜索**：侧栏搜索框按标题和首条消息过滤；`Cmd/Ctrl+Shift+F` 聚焦搜索。
- **置顶 / 归档 / 重命名 / 删除**：会话行右侧 **⋯** 菜单，减少误触；删除需要二次确认。归档的会话可通过“显示归档”查看。
- **会话标题**：第一轮回答完成后会用当前模型生成一个很短的标题（一次小请求），标签和侧栏优先显示它；手动重命名始终优先，生成失败时回退到第一条提问。
- **导出**：会话菜单可导出 Markdown、JSON 或 PDF。
- **编辑并重发**：在用户消息上选择编辑，发送后会重写上一轮；本轮产生的文件改动会保留，可在 diff 中撤销。
- **重新生成**：对最后一条回答重新生成；包含附件的轮次需要先编辑为文本。
- **回退到检查点**：`/rewind` 或命令面板，可选择只回退代码、只回退对话，或两者都回退。
- **分叉会话**：`/fork` 从当前会话复制一份独立对话，原会话不受影响。
- **忙时继续**：回复运行中按 Enter 会把新问题加入队列；纯文本排队项可以点 **在新窗口另开**，从最近一次落盘的会话派生分支，并把父窗口 fork 时刻的状态快照（当前 turn、部分回复、后台 shell/子代理、改动文件）作为隐藏上下文附在问题前，在新窗口自动发送。新窗口能回答“派生时执行到哪里”，但快照不会随后续进展更新。带附件的排队项暂不提供这个入口。
- **恢复损坏会话**：如果加载时检测到 transcript 完整性失败，会提示“恢复损坏会话”，把可解析消息抢救到新会话，原文件不改动。

## 对话目录

右侧 Inspector 的 **目录** 标签（顶栏目录按钮或工具菜单也可打开）列出当前会话的每个提问和回答，点击即可跳转到对应位置。跳转后会自动暂停“跟随底部”，点输入框右侧的 **↓** 恢复跟随。

## 输入、附件与语音

- **Markdown**：输入区支持加粗、斜体、代码、标题、列表、引用和预览；`Cmd/Ctrl+B/I/E` 是格式快捷键。
- **@ 引用**：输入 `@` 搜索工作区文件，选中后作为路径引用插入。
- **附件**：点击回形针选择文档或媒体；也可以直接拖拽文件到窗口、粘贴截图。
- **图片**：粘贴或拖入的图片显示缩略图，保存在 `~/.x-code/attachments`；重新打开历史会话时恢复。
- **截图**：点击截图按钮选择“框选区域”或“整个屏幕”，图片会作为附件加入当前消息。
- **工作区提醒**：消息里出现当前工作区之外的绝对路径（`/Users/...`、`~/...`、`/Volumes/...`、Windows 盘符）时，发送前会提示当前工作区和外部路径。可以确认继续、取消后到侧栏切换项目，或本次会话不再提示。工作区内的路径、URL 和 `/usr`、`/tmp` 等系统路径不会触发。
- **语音**：点击麦克风开始录音，再次点击停止并本地转写。音频不上传；首次使用可能下载 Whisper 模型。
- **文档附件**：PDF、Word、Excel、PPT、Markdown、图片和音频都可以附加。文档文本会本地解析；扫描版 PDF 可使用本地 OCR。
- **消息操作**：用户消息可复制；每轮工具调用可单独展开或整轮收起；回答中的代码块可复制和切换换行。

## 文档与文档库

- **打开文档**：输入框左侧文档图标、`Cmd/Ctrl+Shift+D`、命令面板或 `/doc`。会优先打开当前工作区上次的文档。
- **最近文档标签**：Inspector 顶部直接列出最近文档，点击切换；`Esc` 或右上角关闭。
- **页面与表格**：PDF 支持分页渲染、提取文本、OCR 和跳转页码；Excel 以工作表标签展示；Markdown 有渲染视图。
- **文档问答**：文档面板可以把当前文档附加给对话、请求总结，或按页提问。
- **改动审核**：可编辑文档在打开后被修改时，会提示查看改动并按 hunk 接受，也可以“以当前内容为新基线”。
- **文件浏览器**：文本文件在轻量编辑器中打开；PDF、Word、Excel、PPT 和图片会自动切换到文档面板预览，不再把二进制内容显示成源码。
- **文档库**：设置 → 文档库 可以把工作区文档建成本地索引，支持关键词和可选语义检索。内容不上传。
- **导出**：`documentExport` 工具与文档面板可以把内容导出为 PDF、DOCX、XLSX、CSV 等本地文件。

## 文件产出与临时目录

- Agent 为你创建、需要保留的文件（报告、转写稿、导出文档、生成的图片/音视频等）默认写在**当前工作区**，相对路径以工作区为根目录。
- `/tmp` 只用于可丢弃的中间文件（音频切片、转换暂存等），任务结束前应清理。工具把文件写进系统临时目录时，结果里会附带 `[Output location]` 提醒，Agent 应把交付物移到工作区。
- 工具卡片还会显示「交付物写到了系统临时目录」和**移动到工作区**按钮：当前回复结束后点击，会把文件复制到工作区并删除临时源文件；重名时自动加 `(1)` 后缀，不会覆盖已有文件。
- 技能依赖和受管运行时装在 `~/.x-code/skill-runtime`，技能市场安装的技能在 `~/.x-code/skills`，都不写入工作区；项目里旧安装器留下的 `runtime/`、`venv/` 可以在设置 → 技能里清理。
- 如果确实需要把交付物放到工作区外（例如 `~/Documents`），在提问时直接给出目标路径；Agent 会按你给的路径写入。

## Git 与 worktree

![右侧 Inspector](shot:inspector)

- **Git 变更**：Inspector 的 Git 标签显示当前分支、文件状态、增删统计和 diff。
- **撤销本轮**：如果当前轮存在检查点，可以撤销本轮对文件的修改；也可在单条 diff 卡片上撤销一次编辑。
- **分支窗口**：侧栏项目标题旁的 Git 图标打开分支选择器。选择本地或 `origin/*` 远程分支会在新窗口打开独立 worktree。
- **创建分支**：分支选择器底部可以输入新分支名，并选择父目录；默认在仓库旁边创建 worktree。
- **删除 / 清理**：可以删除 worktree；有未提交改动时需要二次确认。`Prune` 清理已失效的 worktree 记录。
- **安全限制**：主 checkout、当前窗口正在使用的 worktree、被锁定的 worktree 不会被删除。
- **旧版 Git**：低于 2.17 的 Git 会走降级路径，worktree 管理能力可能受限。

## 项目检查

- 打开方式：Inspector 的“检查”标签、命令面板“项目检查”、`/checks`。
- 自动检测 Node（package.json 脚本）和 Cargo 项目的检查命令。
- 可以手动运行、开启“自动检查”（每轮结束后运行），失败时可以一键把失败输出发给 agent 修复。
- 检查在项目目录中执行；输出会截断显示，完整输出会进入修复提示。

## 模型与上下文

![设置](shot:settings)

- **模型选择**：顶栏模型菜单支持搜索、本地模型（Ollama / LM Studio）分组，并显示每个模型的上限。
- **配置提供商**：设置 → 模型与密钥。支持 Anthropic、OpenAI、DeepSeek、Gemini、Qwen、xAI、Zhipu、Moonshot、Kimi 和任意 OpenAI-compatible 端点。
- **测试连接**：每个提供商都有“测试连接”，会实际请求一次并显示延迟和模型 ID。
- **自定义模型**：填写自定义模型 ID 和 base URL；密钥保存在本机。
- **上下文计量**：输入框下方显示已用 / 上限和百分比；达到 80% 会自动压缩，保留最近约 20k tokens。恢复长会话时按当前上下文判断，不会因为历史累计用量提前压缩。
- **上下文上限覆盖**：设置 → 模型与密钥可以为当前模型单独设置上限（≥ 32768 tokens）；只影响该模型，切换模型后可分别配置。
- **切换模型**：切换后保留上一轮用量读数，只替换上限；已打开会话的上下文不会丢失。
- **ChatGPT 登录**：CLI 与桌面端共用登录状态；可以按提供商使用订阅或 API Key。

## 技能、插件与 MCP

![技能市场](shot:skills)

- **技能**：设置 → 技能 查看已安装技能、启用/禁用、从文件或文件夹导入，或粘贴 `npx skills add ...` 命令安装。安装后会自动热重载；也可以点“重新扫描”。外部安装的技能会刷新环境后出现，按钮为“刷新环境”。每个技能如果带有 `requirements.txt`、`pyproject.toml` 或 `package.json`，可以在技能行内点“安装依赖”，依赖会装到 `~/.x-code/skill-runtime/<技能>` 的隔离环境，不会写进项目；也可以清除运行时，或清理旧安装器留在技能目录里的 `runtime/`、`venv/`。
- **技能市场**：设置 → 技能市场 内置 SkillHub 和 SkillsMP。
  - SkillHub：国内优先源，搜索和下载无需登录；安装包会校验路径、大小和 zip 结构。
  - SkillsMP：只读社区目录；匿名搜索有每小时额度，可设置 `SKILLSMP_API_KEY` 使用账号额度；技能从结果指向的 GitHub 仓库安装。
  - SkillsMP 一侧可以把 `https://skillsmp.com/mcp` 注册为用户级 MCP 服务器，让 agent 直接调用 `search_skills` 等工具。
- **插件**：插件市场支持浏览、搜索、安装、启用/禁用和卸载；安装前会显示权限与用户配置预览。也可以从本地目录或 Git 地址导入。
- **MCP**：设置 → MCP 添加 stdio 或 HTTP 服务器；可以查看连接状态、工具数量和认证状态。项目级 MCP 需要先信任项目。
- **子代理**：内置 explore、general-purpose、plan、code-reviewer、goal-verifier；`/list-agents` 查看。自定义 agent 放在用户或项目目录，修改后需要重启应用。
- **自定义命令**：设置 → 命令 或用户目录 `~/.x-code/commands/`；输入 `/命令名` 调用，支持参数。
- **Hooks**：设置 → Hooks 管理用户级和项目级生命周期脚本；项目级 hooks 在信任项目前不会执行。

## 权限与安全

- **三级权限**：始终允许 / 询问 / 拒绝。破坏性 shell 命令、路径校验和计划模式在允许规则之前生效。
- **权限规则**：设置 → 权限 列出当前项目持久化的“不再询问”规则，可添加、删除。shell 支持前缀、精确和整个工具；其他工具只支持整个工具。
- **始终允许**：设置 → 工具 可以按工具开启“始终允许”，或开启“全部工具始终允许”。后者等价于 trustMode，只应在完全信任时使用。
- **Shell 沙箱（macOS）**：agent 的 shell 命令运行在 workspace-write 沙箱中，只能写工作区、临时目录和 `~/.x-code/skill-runtime`，敏感路径不可读写，网络默认关闭，密钥类环境变量会被清理。内置终端不受限制；Hooks 和 stdio MCP 可以选择一并沙箱。内置终端以登录 shell 启动，并强制使用 UTF-8 locale（`LANG`/`LC_CTYPE` 缺失或为 `C` 时改为 `en_US.UTF-8`），中文输入和文件名不会再变成乱码；Agent 每轮前也会刷新登录 shell 的 PATH（缓存 30 秒），所以在电脑终端新装的工具通常不用重启应用。命令以非零状态退出（例如 `grep` 没有匹配、`command -v` 找不到）现在按普通结果展示，只有启动失败、超时、信号终止或沙箱拒绝才会标记为工具失败。
- **沙箱状态始终可见**：沙箱开启且网络关闭时，输入框下方会显示“沙箱 · 网络关闭”标签，点击直接打开设置。联网命令失败后，工具卡片下方会出现说明和“允许网络”“沙箱设置”按钮；设置 → 工具的顶部也会提示，并可以一键允许网络。需要凭证或联网的命令也可以直接在右侧终端执行。工作区外写入失败时同样会提示沙箱只允许写工作区和临时目录。命令报 `command not found` 时，如果刚在电脑终端安装过它，可以在工具卡片上点“刷新环境”重试，无需重启应用。
- **项目信任**：项目级 hooks 和项目 MCP 在信任前不会执行；插件安装有独立同意预览。
- **密钥**：provider API Key 通过系统安全存储或 `0600` 文件保存，不会传回渲染进程。ChatGPT token 目前是明文文件，请像密码一样保护 `~/.x-code/auth/`。
- **联网搜索**：`webSearch` 需要配置一个搜索服务（推荐 Tavily 免费额度），入口在设置 → 工具 → 搜索服务；没配置时模型无法联网搜索，会收到配置提示，`webFetch` 直接抓取网页不受影响。搜索密钥与模型密钥分开保存，同样只留在本机。配置多个服务时可以在“首选搜索服务”里指定使用哪一个，也可以用“测试连接”先验证 Key 是否可用。
- **第三方技能**：技能内容会进入模型上下文。安装前确认来源可信；市场只复制文件，不执行技能里的脚本。

## 自动化与扩展

- **任务模式**：顶栏的编程 / 写作 / 科研 / 办公只调整回答侧重点，不限制工具。空状态推荐由当前工作区动态生成。
- **计划模式**：`/plan` 进入只读探索，agent 先给计划，批准后再写文件。
- **Goal 循环**：`/goal` 让 agent 执行 → 验证 → 修复，直到通过或达到停止条件。
- **后台 shell**：长时间运行的命令超过初始等待会进入“后台任务”面板；如果模型再做一次默认的被动状态检查仍在运行，当前回复会自动结束，输入框马上可以继续提问。输入框上方显示运行中数量和“查看”入口；面板显示运行时长、输出大小、进度条和停止按钮（命令输出百分比时显示确定进度，否则显示活动进度）。
- **后台子代理**：让 Agent 执行较长的独立调查、审查或整理时，它可以用 `task` 的 `background: true` 派发子代理，调用立即返回任务 id。子代理在独立上下文继续运行，面板显示状态、耗时、工具调用数和结果，可单独停止，完成后发系统通知。之后你直接问“现在到哪了”，模型可以调用 `backgroundList`、`backgroundGet`、`backgroundOutput` 读取状态和输出尾部；`backgroundOutput` 默认立即返回，`block: true` 才会等待。每轮开始时，运行中的后台任务摘要也会自动进入模型上下文。子代理结果不会自动并入主对话；完整结果需要在面板查看或让模型用工具读取。
- **后台继续**：回复运行中按 Enter 可以把新问题加入队列；纯文本排队项可点“在新窗口另开”，从最近保存的会话派生分支，并把 fork 时刻的父窗口状态快照（当前 turn、部分回复、后台任务、改动文件）附在问题前，新窗口自动提交；原窗口的当前回复不受影响。快照只代表派生那一刻；新窗口还会通过主进程的共享后台视图看到所有窗口的后台 shell/子代理状态（约 2 秒刷新），可以直接问模型“现在后台任务到哪了”。它仍然看不到父窗口当前模型 turn 的内部推理。如果回复仍在等待后台任务，输入框上方会出现“停止等待”（有排队消息时为“停止等待并执行排队”），只结束当前回复，后台任务继续运行。
- **浏览器子代理**：设置 → 工具 开启后，`task` 可以委派点击、输入、登录等多步浏览器任务；首次使用会通过 `npx @playwright/mcp` 启动受管 Chrome。
- **自动视觉检查**：根代理在显著界面改动后，可对 localhost 截图一次；与浏览器子代理独立开关。
- **记忆**：用户记忆在设置 → 记忆 中管理；项目知识来自 `AGENTS.md` / `AGENTS.local.md` 层级。

## 后台任务查询与跨窗口进度

后台任务不需要你记住 id，也不需要打开面板才能问进度。推荐这样用：

1. 让 Agent 跑长命令，或让它用 `task` 的 `background: true` 派发一个调查/审查任务。
2. 直接在输入框问“现在执行到哪了、进度多少”。模型会调用 `backgroundList` 找到任务，再用 `backgroundGet` / `backgroundOutput` 读取状态、耗时、工具调用数和输出尾部；它不会把没有查询过的状态当作事实。
3. `backgroundOutput` 默认立即返回（`block: false`）。只有你明确说“等它跑完再告诉我”时，模型才应该用 `block: true` 等待，最长 5 分钟。
4. 当前回复仍在运行时，按 Enter 把问题加入队列；纯文本问题可以点“在新窗口另开”。新窗口会得到 fork 时刻的状态快照，并通过主进程共享视图看到其他窗口的后台 shell/子代理（约 2 秒刷新），因此可以直接问“后台任务现在到哪了”。父窗口当前模型 turn 的内部推理不在共享范围内。
5. “后台任务”面板列出所有窗口的 shell 和子代理：本窗口的任务可以直接停止；其他窗口的任务以虚线卡片展示，只能查看状态和输出快照，需要在原窗口停止。

注意：后台任务状态保存在应用进程内，退出应用后未完成的任务会丢失；已经写入 transcript 的输出仍会保留。共享视图只覆盖后台 shell/子代理，不是两个窗口共享同一个模型 turn。

## 设置详解

- **模型与密钥**：提供商、API Key、base URL、自定义模型、连接测试、上下文上限。
- **项目**：当前工作区的模型 / 任务模式 / 自动检查覆盖。
- **技能**：导入、安装命令、启用状态、重新扫描和刷新环境。
- **技能市场**：SkillHub / SkillsMP 搜索与安装、MCP 注册。
- **命令**：用户级和项目级自定义斜杠命令。
- **Hooks**：生命周期脚本和项目信任。
- **记忆**：用户记忆主题的查看、编辑和删除。
- **MCP**：服务器添加、认证、启用和移除。
- **插件 / 插件市场**：安装、配置和卸载。
- **工具**：工具启用、始终允许、工具面、Shell 沙箱、浏览器子代理、搜索服务（Tavily / Brave / Exa 等联网搜索密钥、首选服务与连接测试）、诊断与支持。
- **权限**：持久化允许规则。
- **文档库**：本地索引、语义检索开关、重建和清理。
- **存储**：占用统计、清理、备份与恢复。

## 快捷键与命令面板

- `Cmd/Ctrl+K`：命令面板，可搜索操作、会话、文件和斜杠命令；支持同义词（截图、worktree、技能市场等）。

## 数据、备份与更新

- **数据位置**：会话、技能、插件、记忆、MCP 和设置都在 `~/.x-code`（可用 `X_CODE_HOME` 重定向）。桌面端与 CLI 共用。
- **存储面板**：查看会话、附件、文档库、语音模型占用；清理不会影响当前会话和置顶会话。
- **备份**：设置 → 存储 → 导出备份。备份会话、技能、命令、记忆和子代理；不包含密钥、插件、附件和日志。
- **恢复**：从备份恢复只补充缺失文件，不覆盖现有数据；技能/命令/子代理会立即重载，会话列表会刷新。
- **诊断**：设置 → 工具 → 诊断与支持，或命令面板“导出诊断包”。JSON 快照不包含 API Key、MCP env/header 或命令内容。
- **错误日志**：渲染错误追加到 `~/.x-code/logs/desktop-errors.log`；界面崩溃时显示恢复页，可重新加载或导出诊断。
- **后台任务状态**：后台 shell 和子代理的进度只保存在当前应用进程，跨窗口共享视图也只在应用运行时存在，不进入备份；已经写入会话 transcript 的输出仍会随会话保存。
- **更新**：设置 → 桌面端更新。默认使用官方 GitHub Release 的 `RELEASE.json` 检查新版本，也可以填写自建发布目录的 HTTPS 地址；检查走系统代理。下载时显示已下载大小、速度、百分比和进度条，可随时取消；默认保存到系统“下载”文件夹，也可以点“选择位置”另存。下载完成后显示完整路径和“在 Finder 中显示”，校验 sha256 后手动安装。自动安装仍需要签名应用。

## 故障排查

- **一直使用演示模型**：没有检测到 API Key。到设置 → 模型与密钥填写并测试连接，或检查 `X_CODE_HOME/.env`。
- **模型报最大上下文错误**：到设置 → 模型与密钥降低当前模型的上下文上限，或使用 `/compact` 压缩上下文。
- **MCP 连接失败**：检查命令/URL、网络、认证状态；stdio 服务器需要本机命令存在。项目级服务器需要先信任项目。
- **技能安装失败**：检查网络和代理；SkillsMP 需要能访问 GitHub。macOS 会自动读取系统代理，其他平台可设置 `HTTPS_PROXY`。
- **权限一直询问**：在设置 → 权限添加规则，或对该工具开启“始终允许”；破坏性命令仍会询问。
- **文档空白或没有文字**：扫描版 PDF 需要 OCR；在文档面板点击 OCR，或让 agent 用 `readDocument` 读取。
- **切换工作区很慢或没反应**：切换时侧栏会立即显示进度并禁用重复点击；当前回复运行中会提示先停止。MCP 关闭最多等待约 1.5 秒，会话列表在后台刷新。若仍长时间无响应，检查该工作区是否有大量插件/技能，或导出诊断。
- **后台任务看起来没有结果**：先问 Agent“后台任务到哪了”，它会用 `backgroundList` / `backgroundGet` / `backgroundOutput` 查询；也可以直接打开“后台任务”面板。跨窗口状态每 2 秒同步一次，但父窗口当前模型 turn 的内部推理不在共享范围内。退出应用后未完成的后台任务会丢失，已写入会话的输出仍保留。
- **“在新窗口另开”不可用或失败**：这个入口只对纯文本排队项显示；当前会话还没有落盘、或 transcript 完整性校验失败时无法派生。带附件的问题请先移出队列，直接发送。
- **终端中文乱码**：内置终端会使用 UTF-8 locale；如果自定义环境把 `LANG`/`LC_CTYPE` 设为 `C` 或空值，应用会改为 `en_US.UTF-8`。仍有乱码时，确认命令本身输出的是 UTF-8（例如 `file`、`locale`），或重启该终端标签。
- **终端无法启动**：确认 runtime 已连接；终端使用 PTY，失败信息会显示在顶部。
- **界面白屏**：使用崩溃恢复页重新加载，并导出诊断包；错误日志在 `~/.x-code/logs/desktop-errors.log`。
- **Gatekeeper 阻止打开**：未签名社区版首次打开会提示“无法验证开发者”。macOS 15
  及以后：先关闭提示，再到 **系统设置 → 隐私与安全性 → 安全性 → 仍要打开**，认证后
  再双击应用。若提示“应用已损坏”，先核对 `SHA256SUMS`，再执行
  `xattr -dr com.apple.quarantine /Applications/X-Code.app`。完整步骤见
  `docs/desktop-install-unsigned.md`。

## 已知限制

- Windows / Linux 安装包已经配置 CI，但尚未在真实设备上验收。
- macOS 代码签名、公证和自动安装更新需要 Apple 凭据。
- 真实 LLM E2E 套件需要 provider 凭据，目前 26 个场景已在 `deepseek-flash` 上通过，但仍不纳入默认 CI/发布闸门。
- 后台子代理的结果显示在面板和工具卡片中，不会自动并入主对话的模型上下文；可以用 `backgroundList` / `backgroundGet` / `backgroundOutput` 查询。
- “在新窗口另开”会附带 fork 时刻的状态快照，并通过共享后台视图看到各窗口的后台 shell/子代理（约 2 秒刷新）；但它仍看不到父窗口当前模型 turn 的内部推理，带附件的排队消息也暂不支持。
- 新窗口与原窗口共享工作区，不是同一个会话里的并行 turn；两边同时编辑同一批文件仍可能冲突，编码任务重叠时建议使用 worktree。
- 后台 shell/子代理状态保存在当前应用进程内；退出应用后不会恢复，已经写入会话的输出仍保留在 transcript 中。
- 桌面端 peer 跨会话消息尚未启用。
- 任务模式目前只影响回答侧重点，不改变工具集。
- 关闭窗口时不会自动删除 worktree，避免误删未提交工作。

## 数据与隐私

- 默认不上传遥测；文档解析、OCR、语音转写和文档库都在本机完成。
- 只有对话内容、选中的附件和工具输出会发送给当前模型提供商。
- API Key 不出渲染进程；日志和诊断包不包含密钥、MCP env/header 或命令内容。
- 第三方技能、插件和 MCP 服务器由用户自行选择和信任；安装前请查看来源与权限预览。
